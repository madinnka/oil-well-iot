# Oil Well IoT Controller 🚀

This project is an IoT-based automation and monitoring system for a low-flow oil well using Arduino + ESP-01 (Blynk).

## 🔧 Features
- Pressure monitoring
- Motor current sensing
- Vibration detection
- Automatic relay control
- Manual control via Blynk
- Real-time monitoring from a smartphone

## 🛠 Hardware Used
- Arduino UNO
- ESP-01 Wi-Fi module (AT firmware)
- ACS712 current sensor
- SW-420 vibration sensor
- Analog pressure sensor
- 1-channel relay module

## 📲 Blynk Setup
- V0: Manual motor control (Button)
- V1: Pressure (Display/Graph)
- V2: Motor current
- V3: Vibration status
- V4: Pump status (ON/OFF)
